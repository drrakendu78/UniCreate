# UniCreate - Patch Notes v1.0.8

Date: 2026-05-13
Release tag: `v1.0.8`
Repository: `drrakendu78/UniCreate`

## Highlights

- **ReleaseDate auto-extracted** from the GitHub release date — no more typing `YYYY-MM-DD` by hand.
- **Recent releases dropdown** on the update flow: pick the asset to upload from the 3 latest GitHub releases of the package, instead of pasting the download URL.

## Changes

### 1) Auto-extract `ReleaseDate` from GitHub

- When the user provides a GitHub URL (or picks one of their releases), the backend's `fetch_repo_metadata` now captures `release.published_at` and exposes it as `releaseDate` (formatted as `YYYY-MM-DD` via a new `extract_iso_date` helper).
- `applyRepoMetadata` in the store fills `LocaleData.releaseDate` automatically.
- The YAML generator emits `ReleaseDate` right under `PackageName` — matching the conventional winget-pkgs field ordering. Applied to both `defaultLocale` and additional `locale` manifests.
- A new `Release Date` Field on the **Metadata** step lets users override the auto-extracted value manually if needed.

Impacted files:
- `src-tauri/src/github.rs`
- `src-tauri/src/yaml_generator.rs`
- `src/lib/types.ts`
- `src/stores/manifest-store.ts`
- `src/pages/StepMetadata.tsx`
- `src/pages/StepInstaller.tsx`

### 2) Suggest the 3 latest GitHub releases when updating

- On the **Update Installer** step (when `isUpdate = true`), UniCreate now derives `owner/repo` from the existing manifest URLs (scans `licenseUrl`, `releaseNotesUrl`, `packageUrl`, `publisherUrl`, `publisherSupportUrl`, `privacyUrl`, `copyrightUrl` for a `github.com/<owner>/<repo>` pattern).
- It then calls `fetch_repo_releases` with `count = 3` and renders a "Releases récentes" panel above the URL input.
- Clicking an asset auto-fills the Download URL plus detected architecture and installer type — removing the need to paste the download link by hand on every package bump.

Impacted files:
- `src/pages/StepInstaller.tsx`

### 3) Version bump

- App version updated to `1.0.8`.
